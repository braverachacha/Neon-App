JWT Auth & API Architecture

NeonApp is a decoupled backend focused on JWT Authentication, SMTP integration, and secure API design. Built with Flask, SQLAlchemy, and Flask-Mail.

About NeonApp Backend

The backend provides user authentication and authorization using JWT, email verification via SMTP, and flexible database support (SQLite for dev, PostgreSQL for production).

API Endpoints

  • POST /auth/register – Register a new user
  • POST /auth/login – Authenticate and get JWT
  • POST /auth/forgot-password – Request password reset
  • POST /auth/verify-email – Verify account via email
